# Gestão de Pedidos e Clientes

Sistema web desenvolvido como projeto acadêmico para auxiliar na organização e no gerenciamento de clientes e pedidos de um pequeno negócio.

## Objetivo

Centralizar as informações de clientes e pedidos, facilitando o acompanhamento das solicitações e a organização das atividades.

## Tecnologias previstas

- Python
- Flask
- MySQL
- HTML5
- CSS3
- JavaScript

## Funcionalidades previstas

- Autenticação de usuário.
- Cadastro e consulta de clientes.
- Registro e consulta de pedidos.
- Atualização do status dos pedidos.
- Histórico de pedidos por cliente.

## Status do projeto

Em desenvolvimento.

## Finalidade

Projeto acadêmico do curso de Análise e Desenvolvimento de Sistemas.
